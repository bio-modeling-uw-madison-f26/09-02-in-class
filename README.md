Welcome to your first in-class programming activity! This Jupyter notebook will introduce you to Python, NumPy, and matplotlib while exploring Conway's Game of Life.

## Getting Started

### Option 1: Clone this repository
Open your terminal and run:
```bash
git clone https://github.com/bio-modeling-uw-madison-f26/09-02-in-class.git
cd 09-02-in-class
```

### Option 2: Download directly
1. Go to: https://github.com/bio-modeling-uw-madison-f26/09-02-in-class
2. Click the green "Code" button
3. Select "Download ZIP"
4. Extract the ZIP file to your computer

---

## Running the Notebook

### 1. Open in VS Code
- Open **VS Code**
- Go to `File` → `Open Folder` and select the folder containing this notebook
- Click on `conway.ipynb` in the file explorer

### 2. Select your Python kernel
- When prompted, select a Python interpreter (version 3.8 or higher)
- If no kernel is available, follow the setup instructions below

### 3. Run the cells
- Click the **"Run All"** button at the top, or
- Run cells one by one using `Shift + Enter` on each cell

## Setup Instructions

**If you don't have VS Code:**
- Download and install VS Code: https://code.visualstudio.com/download
- **Need help?** Ask your instructor or TA - we're happy to assist!

**If you don't have Python:**
- Download Python 3.8+ from https://python.org/downloads
- During installation, **check "Add Python to PATH"** (important!)
- **Need help?** Raise your hand and we'll help you set it up!

**If you're missing packages:**
Open VS Code's terminal (`Terminal` → `New Terminal`) and run:
```bash
pip install numpy matplotlib ipython ipywidgets
```

**If you see "kernel not found":**
1. Click the kernel selector (bottom right of VS Code)
2. Choose "Python 3" or "Select another kernel"
3. If none appear, restart VS Code and try again
